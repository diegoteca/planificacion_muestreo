0.1 1. Contexto y Objetivos Generales

En este documento desarrollo el proceso de calibración con fuentes cuasicensales para las muestras de 3.er año y 6.º año de Educación Primaria (PEB 2025).

El objetivo es lograr un vector de ponderadores calibrados (\(w_{\text{cal}}\)) único por estudiante que:

  1. Respete el diseño polietápico original (\(w_{\text{diseño}}\)).
  2. Corrija los sesgos derivados de la no respuesta observada en campo (\(w_{\text{NR}}\)).
  3. Reproduzca exactamente las metas de la publicación cuasicensal, consistentes en una tabla cruzada \(3 \times 2\) entre Sector (Estatal / Privado) y Nivel Socioeconómico (NSE) (Bajo, Medio, Alto), garantizando la coincidencia de:
    • La matrícula poblacional estimada por celda (\(N_h\)).
    • La media poblacional de la prueba de Matemática (\(\bar{Y}_{\text{mat}, h}\)).
    • La media poblacional de la prueba de Lengua / Prácticas del Lenguaje (\(\bar{Y}_{\text{pl}, h}\)).

2.6 11. Exportación de Bases de Estudiantes con Ponderadores

En este bloque guardo las bases finales de estudiantes (tanto en formato .csv como en .rds) conservando toda la trazabilidad de las etapas de muestreo: - pi_1: Probabilidad de inclusión del establecimiento (primera etapa - cubo). - pi_2: Probabilidad condicional de selección de la sección (segunda etapa). - pi_3: Probabilidad condicional del estudiante dentro de la sección (tercera etapa). - pi_total_estudiante: Probabilidad conjunta de inclusión (\(pi_1 \times pi_2 \times pi_3\)). - weight_design: Ponderador base / de diseño inicial (\(1 / pi_{total}\)). - prob_respuesta e inv_no_respuesta: Ajuste por propensión a la respuesta. - weight_no_respuesta: Ponderador ajustado por no respuesta (\(weight\_design \times inv\_no\_respuesta\)). - weight_calibrate: Ponderador final de calibración que reproduce exactamente el cuasicenso en Matemática, Lengua, Sector y NSE.

## 3. Carga del Marco Muestral y Diseño Base (3.er Año)

Cargo el marco muestral y calculo la matrícula estimada de 3.er año:

```{r}
#| label: carga_insumos_marco_3
#| message: false
#| warning: false

marco_muestra = read_rds(here("Outputs", "marco_muestra_rds"))
resultado_segunda_etapa = read_rds(here("Outputs", "resultado_segunda_etapa.rds"))
tb_secciones_2025 = read_xlsx(here("Inputs", "SeccionesdetalladasRA2025.xlsx")) |>
  clean_names() |>
  mutate(total = as.double(total))

# Estimación de la matrícula poblacional de 3er año a partir del ratio en secciones
n_poblacion_3_base_secciones = tb_secciones_2025 |>
  filter(anio == 3, descripcionofertaeducativa == "Primaria (1° Y 2° ciclo)") |>
  summarise(matricula = sum(total))

n_poblacion_primaria_base_secciones = tb_secciones_2025 |>
  filter(descripcionofertaeducativa == "Primaria (1° Y 2° ciclo)") |>
  summarise(matricula = sum(total))

ratio_primaria_terceros = n_poblacion_primaria_base_secciones$matricula / 
                          n_poblacion_3_base_secciones$matricula

marco_muestra = marco_muestra |>
  mutate(
    matricula_3 = matricula_inicial_2025 / ratio_primaria_terceros,
    NSE = case_when(
      ntile(auh_pct, 3) == 1 ~ "Alto",
      ntile(auh_pct, 3) == 2 ~ "Medio",
      ntile(auh_pct, 3) == 3 ~ "Bajo"
    ),
    NSE = factor(NSE, levels = levels_NSE)
  )

n_poblacion_objetivo_3 = marco_muestra |>
  summarise(matricula_3 = sum(matricula_inicial_2025) / ratio_primaria_terceros)
```

## 4. Construcción de Ponderadores de Diseño y No Respuesta (3.er Año)

```{r}
#| label: construccion_ponderadores_base_3
#| message: false
#| warning: false

# 1. Muestra de estudiantes de 3.º
muestra_estudiantes_3 = read_sav(here("Inputs", "PEB_2025", "PEB_Primaria_3er año_Carga por estudiante_2025_con variables de contexto.sav")) |>
  rename(
    clave = CLAVE,
    prioridad_seccion = IM2,
    turno = IM1,
    ira_mat = Puntaje_Mate,
    ira_pl = Puntaje_PL
  ) |>
  mutate(
    anio = 3,
    prioridad_seccion = as_factor(prioridad_seccion),
    sector_superv = if_else(sector_superv == "GP", "Privado", "Estatal"),
    NSE = case_when(
      tercil_AUH == 1 ~ "Alto",
      tercil_AUH == 2 ~ "Medio",
      tercil_AUH == 3 ~ "Bajo"
    ),
    NSE = factor(NSE, levels = levels_NSE)
  )

# 2. Etapa 1: Probabilidad del establecimiento (cubo)
prob_seleccion_primera_etapa = marco_muestra |>
  select(clave, pi_corregido)

insumo_calibracion_3 = muestra_estudiantes_3 |>
  left_join(prob_seleccion_primera_etapa, by = "clave") |>
  rename(pi_1 = pi_corregido)

# 3. Etapa 2: Probabilidad de selección de sección
prob_seleccion_segunda_etapa = resultado_segunda_etapa |>
  rename(prioridad_seccion = rol, size_seccion = total) |>
  mutate(
    prioridad_seccion = case_when(
      prioridad_seccion == "Suplente/Complementaria" ~ "Suplente",
      .default = prioridad_seccion
    ),
    azar_desempate = runif(n())
  ) |>
  group_by(clave, anio) |>
  mutate(
    max_prob_reserva = if (any(prioridad_seccion == "Reserva")) {
      max(prob_seleccion[prioridad_seccion == "Reserva"], na.rm = TRUE)
    } else { NA_real_ }
  ) |>
  filter(
    prioridad_seccion %in% c("Principal", "Suplente") |
    (prioridad_seccion == "Reserva" & prob_seleccion == max_prob_reserva)
  ) |>
  arrange(prioridad_seccion, desc(prob_seleccion), desc(azar_desempate), .by_group = TRUE) |>
  distinct(clave, anio, prioridad_seccion, .keep_all = TRUE) |>
  ungroup() |>
  select(idseccion, clave, anio, prioridad_seccion, prob_seleccion, size_seccion)

insumo_calibracion_3 = insumo_calibracion_3 |>
  mutate(prioridad_seccion = if_else(clave == "0104PP0002", "Principal", prioridad_seccion)) |>
  left_join(prob_seleccion_segunda_etapa, by = join_by(clave, anio, prioridad_seccion)) |>
  rename(pi_2 = prob_seleccion)

# 4. Etapa 3 y Ponderador de Diseño
insumo_calibracion_3 = insumo_calibracion_3 |>
  add_count(clave, anio, idseccion, name = "pik_estudiantes_seccion") |>
  mutate(
    pi_3_diseno = pik_estudiantes_seccion / size_seccion,
    pi_3 = pmin(pi_3_diseno, 1),
    pi_total_estudiante = pi_1 * pi_2 * pi_3,
    weight_design = 1 / pi_total_estudiante
  )

# 5. Ajuste por No Respuesta (Propensity Score)
df_no_respuesta_3 = marco_muestra |>
  filter(muestra_2025 == 1) |>
  mutate(respuesta_muestra = as.numeric(clave %in% insumo_calibracion_3$clave))

modelo_propension_3 = glm(
  respuesta_muestra ~ matricula_inicial_2025 + auh_pct + Region * sector + jornada_completa * ambito,
  data = df_no_respuesta_3,
  family = binomial(link = "logit")
)

df_no_respuesta_3 = df_no_respuesta_3 |>
  mutate(prob_respuesta = predict(modelo_propension_3, type = "response"))

factores_modelo_3 = df_no_respuesta_3 |>
  filter(respuesta_muestra == 1) |>
  select(clave, prob_respuesta) |>
  mutate(inv_no_respuesta = 1 / prob_respuesta)

insumo_calibracion_3 = insumo_calibracion_3 |>
  left_join(factores_modelo_3, by = "clave") |>
  mutate(weight_no_respuesta = weight_design * inv_no_respuesta) |>
  left_join(
    marco_muestra |>
      select(clave, sector_marco = sector, region_marco = Region, ambito_marco = ambito, jornada_completa, matricula_3, auh_pct),
    by = "clave"
  ) |>
  mutate(
    id_estudiante = row_number(),
    fpc = n_poblacion_objetivo_3$matricula_3,
    sector = as.factor(sector_superv),
    NSE = as.factor(NSE),
    ambito = as.factor(ambito_marco),
    region = as.factor(region_marco),
    zona = as.factor(if_else(as.numeric(as.character(region_marco)) %in% 1:11, "Conurbano", "Interior")),
    jornada_completa = as.factor(jornada_completa)
  )
```

## 5. Calibración y Diagnóstico (3.er Año)

```{r}
#| label: preparacion_calibracion_3

# 1. Matrícula poblacional por celda del marco
marco_muestra = marco_muestra |>
  mutate(zona = if_else(as.numeric(as.character(Region)) %in% 1:11, "Conurbano", "Interior"))

marco_celdas_3 = marco_muestra |>
  group_by(sector, NSE) |>
  summarise(N_celda = sum(matricula_3, na.rm = TRUE), .groups = "drop")

# 2. Metas de control
control_celdas_3 = medias_cuasicenso_3 |>
  left_join(marco_celdas_3, by = c("sector", "NSE")) |>
  mutate(
    T_mat = media_mat_ref * N_celda,
    T_pl  = media_pl_ref  * N_celda
  )

# 3. Imputación interna de notas en la muestra
insumo_calibracion_3 = insumo_calibracion_3 |>
  group_by(sector, NSE) |>
  mutate(
    ira_mat_imp = if_else(is.na(ira_mat), mean(ira_mat, na.rm = TRUE), ira_mat),
    ira_pl_imp  = if_else(is.na(ira_pl),  mean(ira_pl, na.rm = TRUE), ira_pl)
  ) |>
  ungroup()

# 4. Variables auxiliares (18 variables de celda + marginal de Zona)
for(s in c("Estatal", "Privado")) {
  for(n in c("Bajo", "Medio", "Alto")) {
    var_celda = paste0("celda_", s, "_", n)
    var_mat   = paste0("mat_", s, "_", n)
    var_pl    = paste0("pl_", s, "_", n)
    
    insumo_calibracion_3 = insumo_calibracion_3 |>
      mutate(
        !!var_celda := as.numeric(sector == s & NSE == n),
        !!var_mat   := as.numeric(sector == s & NSE == n) * ira_mat_imp,
        !!var_pl    := as.numeric(sector == s & NSE == n) * ira_pl_imp
      )
  }
}

# 5. Diseño y fórmula
diseno_muestra_3 = insumo_calibracion_3 |>
  as_survey_design(ids = id_estudiante, weights = weight_no_respuesta, fpc = fpc)

formula_calib_3 = ~ -1 + 
  celda_Estatal_Bajo + celda_Estatal_Medio + celda_Estatal_Alto +
  celda_Privado_Bajo + celda_Privado_Medio + celda_Privado_Alto +
  mat_Estatal_Bajo + mat_Estatal_Medio + mat_Estatal_Alto +
  mat_Privado_Bajo + mat_Privado_Medio + mat_Privado_Alto +
  pl_Estatal_Bajo + pl_Estatal_Medio + pl_Estatal_Alto +
  pl_Privado_Bajo + pl_Privado_Medio + pl_Privado_Alto

vector_totales_3 = c(
```

## 8. Construcción de Ponderadores de Diseño y No Respuesta (6.º Año)

```{r}
#| warning: false

  rename(
    clave = CLAVE,
    prioridad_seccion = IM2,
    turno = IM1,
    ira_mat = Puntaje_Mate,
    ira_pl = Puntaje_PL
  ) |>
  mutate(
    anio = 6,
    prioridad_seccion = as_factor(prioridad_seccion),
    sector_superv = if_else(sector_superv == "GP", "Privado", "Estatal"),
    NSE = case_when(
      tercil_AUH == 1 ~ "Alto",
      tercil_AUH == 2 ~ "Medio",
      tercil_AUH == 3 ~ "Bajo"
    ),
    NSE = factor(NSE, levels = levels_NSE)
  )

# 2. Probabilidades e insumo 6
prob_seleccion_segunda_etapa_6 = resultado_segunda_etapa |>
  rename(prioridad_seccion = rol, size_seccion = total) |>
  mutate(
    prioridad_seccion = case_when(
      prioridad_seccion == "Suplente/Complementaria" ~ "Suplente",
      .default = prioridad_seccion
    ),
    azar_desempate = runif(n())
  ) |>
  group_by(clave, anio) |>
  mutate(
    max_prob_reserva = if (any(prioridad_seccion == "Reserva")) {
      max(prob_seleccion[prioridad_seccion == "Reserva"], na.rm = TRUE)
    } else { NA_real_ }
  ) |>
  filter(
    prioridad_seccion %in% c("Principal", "Suplente") |
    (prioridad_seccion == "Reserva" & prob_seleccion == max_prob_reserva)
  ) |>
  arrange(prioridad_seccion, desc(prob_seleccion), desc(azar_desempate), .by_group = TRUE) |>
  distinct(clave, anio, prioridad_seccion, .keep_all = TRUE) |>
  ungroup() |>
  select(idseccion, clave, anio, prioridad_seccion, prob_seleccion, size_seccion)

insumo_calibracion_6 = muestra_estudiantes_6 |>
  left_join(prob_seleccion_primera_etapa, by = "clave") |>
  rename(pi_1 = pi_corregido) |>
  left_join(prob_seleccion_segunda_etapa_6, by = join_by(clave, anio, prioridad_seccion)) |>
  rename(pi_2 = prob_seleccion) |>
  # En caso de que alguna sección no coincida exactamente por etiqueta, imputar la probabilidad media de sección
  mutate(pi_2 = if_else(is.na(pi_2), 1, pi_2),
         size_seccion = if_else(is.na(size_seccion) | size_seccion == 0, 10, size_seccion)) |>
  add_count(clave, anio, idseccion, name = "pik_estudiantes_seccion") |>
  mutate(
    pi_3_diseno = pik_estudiantes_seccion / size_seccion,
    pi_3 = pmin(pi_3_diseno, 1),
    pi_total_estudiante = pi_1 * pi_2 * pi_3,
    weight_design = 1 / pi_total_estudiante
  )

# 3. No respuesta 6
df_no_respuesta_6 = marco_muestra |>
  filter(muestra_2025 == 1) |>
  mutate(respuesta_muestra = as.numeric(clave %in% insumo_calibracion_6$clave))

modelo_propension_6 = glm(
  respuesta_muestra ~ matricula_inicial_2025 + auh_pct + Region * sector + jornada_completa * ambito,
  data = df_no_respuesta_6,
  family = binomial(link = "logit")
)

df_no_respuesta_6 = df_no_respuesta_6 |>
  mutate(prob_respuesta = predict(modelo_propension_6, type = "response"))

factores_modelo_6 = df_no_respuesta_6 |>
  filter(respuesta_muestra == 1) |>
  select(clave, prob_respuesta) |>
  mutate(inv_no_respuesta = 1 / prob_respuesta)

insumo_calibracion_6 = insumo_calibracion_6 |>
  left_join(factores_modelo_6, by = "clave") |>
  mutate(weight_no_respuesta = weight_design * inv_no_respuesta) |>
  left_join(
    marco_muestra |>
      select(clave, sector_marco = sector, region_marco = Region, ambito_marco = ambito, jornada_completa, matricula_6, auh_pct),
    by = "clave"
  ) |>
  mutate(
    id_estudiante = row_number(),
    fpc = n_poblacion_objetivo_6$matricula_6,
    sector = as.factor(sector_superv),
    NSE = as.factor(NSE),
    ambito = as.factor(ambito_marco),
    region = as.factor(region_marco),
    zona = as.factor(if_else(as.numeric(as.character(region_marco)) %in% 1:11, "Conurbano", "Interior")),
    jornada_completa = as.factor(jornada_completa)
  )
```

## 11. Exportación de Bases de Estudiantes con Ponderadores

En este bloque guardo las bases finales de estudiantes (tanto en formato `.csv` como en `.rds`) conservando toda la trazabilidad de las etapas de muestreo:
- `pi_1`: Probabilidad de inclusión del establecimiento (primera etapa - cubo).
- `pi_2`: Probabilidad condicional de selección de la sección (segunda etapa).
- `pi_3`: Probabilidad condicional del estudiante dentro de la sección (tercera etapa).
- `pi_total_estudiante`: Probabilidad conjunta de inclusión ($pi_1 \times pi_2 \times pi_3$).
- `weight_design`: Ponderador base / de diseño inicial ($1 / pi_{total}$).
- `prob_respuesta` e `inv_no_respuesta`: Ajuste por propensión a la respuesta.
- `weight_no_respuesta`: Ponderador ajustado por no respuesta ($weight\_design \times inv\_no\_respuesta$).
- `weight_calibrate`: Ponderador final de calibración que reproduce exactamente el cuasicenso en Matemática, Lengua, Sector y NSE.

```{r}
#| label: exportacion_bases_calibradas
```
